# Contributing Guidelines

Thank you for your interest in contributing to the Simple Interest Calculator project.

All contributions are welcome.

We welcome:

- Bug reports
- Bug fixes
- Documentation improvements
- Enhancements
- Ideas and suggestions

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes.
5. Commit your changes with a clear commit message.
6. Push your changes to your fork.
7. Create a pull request.

## Bug Reports

If you find a bug, please provide a clear description of the problem and steps to reproduce it.

## Documentation

Documentation improvements are welcome. Please make sure that documentation is clear and accurate.

## Enhancements

Enhancements and new ideas that improve the project are welcome.

Thank you for contributing to the project!
