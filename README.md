# Simple Interest Calculator

A simple Bash script that calculates simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

The script asks the user to enter:

- Principal amount
- Rate of interest
- Time period

## Output

The script calculates and displays the simple interest.

## Usage

Run the script using:

```bash
bash simple-interest.sh
