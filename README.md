# Simple Interest Calculator

A simple Bash script to calculate simple interest based on the principal amount, rate of interest, and time period.

## Project Description

The Simple Interest Calculator is an open source project developed for a micro-finance startup. It allows users to calculate simple interest using the principal amount, rate of interest, and time period provided by the user.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

The program requires the following inputs:

- Principal amount
- Rate of interest
- Time period

## Output

The program displays the calculated simple interest.

## How to Run

Run the script using:

bash simple-interest.sh

## Example

Simple Interest Calculator
Enter Principal: 10000
Enter Rate of Interest: 5
Enter Time Period: 2
Simple Interest: 1000.00
